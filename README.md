# pomme019.github.io

Portafolio de **Isabel Cock** — animación experimental, pintura, grabado e ilustración.

- Sitio: <https://pomme019.github.io/>
- Contexto para agentes: `AGENTS.md`
- Textos y fichas: `CONTENIDO.md`
- Página: `index.html` (CSS y JS inline)
- Imágenes optimizadas: `imagenes/`

## Publicar

Subir `index.html`, `imagenes/`, `favicon.svg`, `robots.txt` y `sitemap.xml` a la raíz de la rama `main`. GitHub Pages publica automáticamente desde la raíz.

El sitio está publicado en <https://pomme019.github.io/>. Para actualizarlo, haz push a `main` (Git está en `C:\Program Files\Git\cmd\git.exe`) o sube los archivos desde la web de GitHub.

## Editar

1. Cambiar textos o fichas en `CONTENIDO.md`.
2. Actualizar el bloque correspondiente en `index.html`.
3. Sustituir la imagen en `imagenes/` manteniendo el nombre de archivo.
4. Abrir `index.html` en el navegador y comprobar móvil/escritorio.
